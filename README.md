# Andika Pratama — Portfolio
Website portfolio pribadi yang dibuat untuk memperkenalkan diri, menampilkan proyek yang saya kerjakan, dan mendokumentasikan perjalanan saya dalam mempelajari front-end development.

## 📌 Tentang
Portfolio ini merupakan tempat saya bereksperimen dengan desain, teknologi web, dan berbagai pendekatan dalam membangun antarmuka yang responsif dan nyaman digunakan.
Project ini juga terus dikembangkan seiring bertambahnya pengalaman dan kemampuan saya dalam web development.

## ✨ Fitur
- Desain responsif untuk desktop, tablet, dan mobile
- Dark mode dengan tampilan modern
- Navigasi sticky
- Scroll progress indicator
- Animasi dan interaksi yang ringan
- Showcase proyek dan case study
- Section workflow pengembangan
- Form kontak
- Struktur JavaScript yang modular
- Fokus pada aksesibilitas dan performa
